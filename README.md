# CashControl

Десктопное приложение для удалённого управления кассовыми терминалами (SetRetail):
SSH-терминал, встроенный VNC-просмотр, редактор PostgreSQL, выполнение команд и
диагностика оборудования.

## Возможности

- **SSH-терминал** — встроенный терминал с HTML-эмулятором (работает как отдельный
  процесс) или внешний клиент (KiTTY и др.). Автоподключение с паролем из настроек,
  TOFU-проверка ключа хоста, сниппеты команд с инлайн-автодополнением,
  прокрутка (scrollback), копирование выделением, смена шрифта
- **Вкладки касс** — одновременная работа с несколькими терминалами, смена IP на лету
- **Встроенный VNC** — pure-Python RFB-клиент с переключением битности (8/16/32 бита)
  и внешним вьюером
- **Информация о кассе** — параллельный сбор данных (ОС, CPU, ПО, оборудование) с
  ленивой загрузкой коллекторов; расширяется TOML-коллекторами
- **Чекер проблем** — автоматическая диагностика типовых неисправностей при подключении;
  правила «Проблем» задаются TOML-файлами без кода
- **Редактор БД** — просмотр и редактирование таблиц PostgreSQL с SQL-подсветкой,
  SQL-консолью и экспортом/импортом CSV
- **Команды** — встроенные (TOML) и пользовательские (JSON/Python) команды,
  hot-reload без перезапуска
- **Аудит и логи** — журнал действий и уведомления в нижней панели
- **Горячие клавиши** — Ctrl+V встроенный VNC, Ctrl+Shift+V внешний VNC, Ctrl+S SSH,
  Ctrl+W WinSCP, Ctrl+D редактор БД, Ctrl+R рестарт ПО, Ctrl+Shift+R перезагрузка кассы

## Требования

- Windows 10/11
- Python **3.12–3.13**
- [uv](https://docs.astral.sh/uv/) (рекомендуется) или pip

## Запуск из исходников

```bat
git clone https://github.com/debrozer-sketch/CashControl.git
cd CashControl

uv venv --python 3.12 .venv
uv pip install -e .

.venv\Scripts\python -m cashcontrol.main
```

или через pip:

```bat
py -3.12 -m venv .venv
.venv\Scripts\activate
pip install -e .
python -m cashcontrol.main
```

При первом запуске откроется мастер настройки: логины/пароли SSH и БД,
пути к KiTTY / WinSCP / VNC-вьюеру (можно найти автоматически). Если для SSH
не указан внешний клиент — используется встроенный терминал.

## Сборка

Сборка portable-версии через Python-скрипт (без Nuitka, embedded Python):

```bat
uv run python scripts/build_dist.py
```

Результат — `dist\CashControl\`: переносимая папка с `CashControl.exe`
и встроенным Python. Сборка инсталлятора — Inno Setup 6:

```
"C:\Program Files (x86)\Inno Setup 6\ISCC.exe" CashControl.iss
```

Результат — `dist\installer\CashControl-setup-<версия>.exe`: установка per-user
без прав администратора, обновление поверх старых версий сохраняет настройки.
Подробнее — `BUILD.md`.

## Структура проекта

```
src/cashcontrol/
  core/          SSH, БД, сессии, команды, безопасность
  gui/           окна, вкладки, тулбар, VNC, диалоги, темы,
                 ssh_terminal_launcher.py (запуск встроенного терминала)
  infrastructure/ конфиг, пути, загрузчики модулей, обновления, аудит-лог
builtin_terminal/ vendored SSH-терминал (PySide6, отдельный процесс)
collectors/      TOML-коллекторы информации о кассе
commands/        пользовательские команды (TOML/Python)
docs/patch.md    история изменений (показывается в «О программе»)
tests/           тесты
```
