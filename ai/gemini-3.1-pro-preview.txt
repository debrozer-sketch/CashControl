Вот готовое решение для визуальной системы **CashControl**, спроектированное по вашему брифу с учётом специфики профессионального десктоп-инструмента и ограничений фреймворка.

---

### 1. Концепция: "Pro Fluent Density"

Для CashControl выбран стиль **Компактный Fluent (Density Fluent)**. Оригинальный Fluent Design из Windows 11 слишком «воздушный» и рассчитан на тач-интерфейсы, что критично съедает место на экранах 1366×768. Наш подход заимствует эстетику (скругления 8px, мягкие контрасты, акценты на состояниях), но уплотняет сетку (отступы кратны 4px) по аналогии с Visual Studio Code или SSMS. Информационные карточки визуально изолированы мягкими рамками, а цветовое кодирование (статусы пинга и касс) выведено на первый план для мгновенного считывания состояния парка терминалов.

### 3. Спецификация компонентов

1.  **Левый сайдбар:** Ширина 48px. Иконки 20x20px. Фон прозрачный (наследует `@bg_app`). При наведении — мягкий `@bg_surface_hover` со скруглением 6px. Активная вкладка отмечается вертикальной линией `@accent` слева (ширина 3px, скругление 2px).
2.  **Вкладки касс (TabBar):** Высота 36px. Текст 9pt Segoe UI, отсечение через эллипсис (...). Индикатор статуса пинга — кружок (QPainter) 8x8px слева от текста. Активная вкладка сливается по цвету с рабочей областью (`@bg_surface`), неактивные — прозрачные.
3.  **Тулбар действий:** Кнопки — `TransparentToolButton` (из qfluentwidgets). Расположение вертикальное (Иконка 24x24 сверху, текст 8pt снизу). Внутренние отступы кнопок: 4px. Запас по ширине для русского текста (+15% к ширине иконки).
4.  **Инфо-панель (Карточки):** Фон `@bg_surface`, граница 1px `@border_light`, радиус 8px (CardWidget). Внутри: `label` (8pt, `@text_secondary`) и `value` (9pt, Bold, `@text_primary`). Расстояние между строками 4px. При загрузке отображается `IndeterminateProgressRing`.
5.  **Статус-бар:** Высота 28px. Текст 8pt. При раскрытии — панель в виде всплывающего окна (Flyout) с фоном Acrylic (если поддерживается) или `@bg_surface`, с тенью.
6.  **DB Viewer (QTableView):** Высокая плотность. Высота строки 24px. Сетка: 1px сплошная `@border_light`. Чередование строк (AlternateRowColors). Выделенная строка: фон `@accent` с прозрачностью 20%, текст остается читаемым.

**Патч 2: Виджет-индикатор пинга в табах (Micro-widget на QPainter) для `gui/tab_bar.py`**
```python
from PySide6.QtWidgets import QWidget
from PySide6.QtGui import QPainter, QColor, QRenderHint
from PySide6.QtCore import Qt

class PingIndicator(QWidget):
    """
    Маленький круговой индикатор пинга. 
    Цвет обновляется через set_status.
    """
    def __init__(self, parent=None):
        super().__init__(parent)
        self.setFixedSize(12, 12)
        self._color = QColor("#616161") # Дефолт (серый)

    def set_status(self, color_hex: str):
        self._color = QColor(color_hex)
        self.update()

    def paintEvent(self, event):
        painter = QPainter(self)
        painter.setRenderHint(QRenderHint.Antialiasing)
        painter.setPen(Qt.NoPen)
        painter.setBrush(self._color)
        # Рисуем кружок по центру (8x8)
        painter.drawEllipse(2, 2, 8, 8)
```
*Использование:* Вставлять этот виджет в структуру кастомного таба (если используется кастомный таб `qfluentwidgets`) или размещать рядом с текстом.

### 6. Чего сознательно НЕ делаю и почему

1. **Не использую эффект Acrylic (Mica/Aero) на главном фоне (`QMainWindow`).** На Windows 10 поддержка Acrylic поверх сторонних окон через PySide часто вызывает артефакты изменения размера окна, лаги при перетаскивании или черный фон. Выбран надежный Solid-подход (`@bg_app`). Acrylic от `qfluentwidgets` оставлен только для всплывающих элементов (Flyouts, ComboBox), где он стабилен.
2. **Не меняю структуру левого сайдбара на дерево (TreeView).** В брифе указана "колонка круглых кнопок-иконок". Для переключения контекста (Кассы / Настройки) это лучший паттерн; добавление текста сделает интерфейс перегруженным.
3. **Не использую системные цвета Windows (Accent Color).** Приложение для мониторинга (с цветовым кодированием статусов зеленый/желтый/красный) должно иметь предсказуемую палитру. Системный акцент (например, красный от пользователя) сломает логику "красный = ошибка".
4. **Не трогаю асинхронные вызовы и потоки DB Viewer'а.** Стилизация QTableView осуществляется исключительно через QSS (сетка, hover) и настройки QHeaderView, без необходимости писать кастомные делегаты `QStyledItemDelegate`, что могло бы повлиять на производительность отрисовки больших датасетов PostgreSQL.
