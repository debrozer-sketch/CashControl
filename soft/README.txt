Папка soft/ — внешние программы для CashControl
================================================

Положите сюда следующие файлы:

  kitty.exe           — SSH клиент (https://sw.kovidgoyal.net/kitty/)
  vncviewer_new.exe   — RealVNC Viewer (https://www.realvnc.com/en/connect/download/viewer/)
  WinSCP.exe          — WinSCP (https://winscp.net/eng/download.php)

Программы будут использоваться автоматически.
Пути можно изменить в Настройки → Программы.
