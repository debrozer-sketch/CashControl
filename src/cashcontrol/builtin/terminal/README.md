# SSH Terminal — прототип

Минималистичный SSH-терминал в стиле PuTTY/KiTTY. Python 3.12+, PySide6, asyncssh, pyte.

## Запуск

Дважды кликни `run.bat` — при первом запуске он сам создаст venv, поставит
зависимости и стартует терминал. На рабочем ПК нужен только установленный
Python (галочка "Add to PATH" при установке не обязательна — батник ищет py-launcher).

## Управление (меню нет — всё как в PuTTY)

### Контекстное меню терминала
- **Правый клик (ПКМ)** — умное меню:
  - есть выделение → **копировать**
  - нет выделения → **вставить**
- **Shift + ПКМ** — полное контекст-меню:
  Копировать / Вставить / Выделить всё / Очистить буфер / Сбросить терминал,
  **Режим стрелок** (авто / обычный / application — если mc не реагирует на
  стрелки, переключи вручную; выбор запоминается), **Лог ввода**, Сниппеты

### Главное меню программы
- **Ctrl+Alt+M** — попап-меню со всеми действиями (подключение, настройки,
  сниппеты, шрифт, выход)
- Клик по значку окна (или Alt+Space, если не занято) — то же в системном меню

### Диагностика
- **Ctrl+Alt+D** — дамп сырого вывода хоста в `session_dump.log`
  (включи, повтори проблему, выключи — и пришли файл)

### Горячие клавиши
| Действие | Клавиши |
|---|---|
| Новое подключение | Ctrl+N или Ctrl+T |
| Закрыть вкладку | Ctrl+W |
| Следующая/предыдущая вкладка | Ctrl+Tab / Ctrl+Shift+Tab |
| Шрифт крупнее / мельче / сброс | Ctrl++ / Ctrl+- / Ctrl+0 |
| Копировать (при выделении) | Ctrl+Shift+C |
| Вставить | Ctrl+Shift+V или Shift+Insert |
| Быстрый выбор сниппета | Ctrl+Space |
| Прокрутка буфера | Shift+PgUp / Shift+PgDn |
| Локальное выделение, когда приложение захватило мышь | Shift + мышь |
| Локальная прокрутка в mc/htop | Shift + колесо |

### Мышь в терминале
- Обычный вывод — выделяй мышью (двойной клик = слово, тройной = строка)
- mc/htop/vim с мышью — события уходят приложению
- Shift отменяет захват мыши приложением (для выделения текста)

## Данные и настройки
- Всё хранится **portable**: в подпапке `data\app\` рядом с программой
  (профили, сниппеты, настройки, known_hosts) — система не засоряется
- ВАЖНО при переносе: архив распаковывай в одну и ту же папку, иначе
  данные не подхватятся (или перенеси `data\app` со старой папки)

## Ограничения прототипа
- Автопереподключение не реализовано
- Telnet/Serial/Mosh — нет (только SSH)
