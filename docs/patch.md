# История изменений CashControl

---

## v3.8.0 — 2026-08-23 (ветка proto, рефакторинг по gap-отчёту)

Серия изменений v3.4–v3.8 выполнена в ветке `proto` (копия проекта
`D:\Project\CashControl4`); `main` не затронут.

### v3.8 — Диагностика на классах

- `PROBLEM_RULES` (список dict с lambda) переведены на ABC
  `DiagnosticCheck` (`core/info/rules.py`): BankUsbModeCheck,
  PaymentRanksCheck, DrawerCloseCheck; применимость — через фичи типов
  (`drawer_close` добавлена в pos/touch). API `ProblemChecker` не менялся.

### v3.7 — DB Viewer разбит из монолита

- 2070-строчный `db_viewer_widget.py` → пакет `gui/db_viewer/`
  (constants/formatting/storage/workers/sql/data_grid/data_panel/
  csv_import/sql_console/tables_panel/widget). Hot-оверлей и префикс
  в module_loader переключены на пакет.

### v3.6 — Session API (ADR-004) и DI

- `core/session_interface.py`: ABC SessionInterface + ExecResult;
  CashSession реализует его, фасадные ping/exec/upload/download/reboot.
- Убраны обращения GUI к приватным атрибутам сессии
  (`_conn`/`_is_connected`): используется `session.abort()`,
  публичные свойства `session`/`keyboard_model`/`successful_password`.
- ConfigManager внедряется опциональным параметром (ssh/db/session/
  password_manager/info_manager); единый реестр коллекторов
  (`core/info/registry.py`, SECTION_ALIASES), info_manager больше не
  дублирует таблицу.
- `asyncio.get_event_loop()` → `get_running_loop()` в пинге.

### v3.5 — Система типов касс cash_types (ADR-003/005)

- Новое ядро `core/cash_types/`: Pydantic-модели, deep-merge extends
  (union/replace, детект циклов), реестр bundled+overlay
  (`cash_types/*.toml` рядом с программой перекрывают встроенные),
  TypeDetector со стратегиями xml_keywords/regex_file/shell и правилами
  из `detection/*.toml`.
- Встроенные типы pos/touch/sco/sco3 (+ detection/default.toml).
- Хардкоды переведены на фичи: barcode/scales from_db, payment_ranks,
  keyboard (коллектор+тулбар), customer_display, qrid, fiscal_register,
  авто-подключение БД через connection.db, секции инфопанели.
- HOT: типы перечитываются при открытии меню «Команды»; ручной выбор
  типа при unknown («Команды → Тип кассы: выбрать вручную…»).
- Тесты: tests/test_cash_types.py (14).

### v3.4 — Безопасность и гигиена

- SSH: проверка host key через data/known_hosts (TOFU при первом
  контакте, громкая ошибка при подмене ключа), алгоритмы ed25519/ecdsa
  добавлены (ревью #18/#19).
- Мастер-ключ шифрования защищён DPAPI; legacy plaintext .keystore
  мигрирует автоматически; повреждённый keystore → понятная ошибка
  вместо тихой регенерации (ревью #16/#17).
- Возвращены data/usb_id_mapping.json и port_mapping.json; удалены
  мёртвые core/mover|reinstall; зависимости loguru/sqlalchemy[asyncio]/
  nuitka вычищены; sync_version.py обновляет и `__init__.py`.

### Упаковка

- `scripts/build_dist.py` собирает portable-раскладку без Nuitka:
  embedded Python в `runtime/python`, бинарные пакеты папками +
  site-packages.zip в `runtime/lib`, код `.py` в `runtime/app`.
  Лаунчер `CashControl.cmd`. Проверено: запуск, перенос на другой диск,
  переименование папки.

## v3.3.0 — 2026-08-22

### Что нового

- **Единый стиль интерфейса (Fluent).** Все окна программы приведены к одному
  оформлению: кнопки с иконками вместо эмодзи, единые диалоги подтверждения,
  неблокирующие всплывающие уведомления вместо модальных окон там, где
  не требуется ответ.
- **Настройки стали компактнее.** Верхние вкладки заменены на меню слева;
  убраны лишние отступы и пустое пространство, окно открывается ниже.

### Что исправлено

- Исправлена установка программы: папки данных и логов создаются внутри
  папки программы, а не рядом с ней; горячая загрузка GUI-модулей теперь
  реально работает в собранной версии.
- Иконка приложения снова применяется при сборке.
- Сборка ускорена: из дистрибутива исключены тестовые наборы библиотек
  и неиспользуемая зависимость loguru.

### Изменения

- Панель инструментов: «Добавить кассу», «Обновить», «Настройки» — кнопки
  с иконками; подтверждение перезагрузки и выполнение команд — в едином стиле.
- Вкладки касс: цветные индикаторы состояния подстраиваются под тему;
  контекстное меню с иконками.
- Нижняя панель: «История»/«Уведомления» — иконки с подсветкой активной вкладки;
  статусы действий текстом и цветом; «Очистить» — компактная иконка.
- Информация о кассе: состояния оборудования читаются из текста
  («подключено/отключено»), акцентная кнопка «Переподключить», строка смены IP
  переведена на общие поля ввода и кнопки.
- Диалоги (добавление кассы, справочник оборудования, конструктор команд,
  результат команды, просмотр логов) — fluent-кнопки, подписи справа по одной
  колонке, одна главная кнопка в каждом диалоге.
- Просмотр журнала: подсветка уровней из палитры темы — корректно выглядит
  в светлой теме; поиск без эмодзи; кнопки с иконками.
- Справка: шапка в цвете темы, содержимое перерисовывается при смене темы,
  из текстов убраны эмодзи.
- Все цвета интерфейса берутся из единой палитры темы.

## v3.2.0 — 2026-08-22

### Что нового

- **Полностью новый редактор базы данных.** Быстрее, красивее и удобнее прежнего:
  - список баз и таблиц с поиском и понятными значками;
  - клик по таблице показывает её свойства — число строк, размер, количество колонок;
  - несколько таблиц открываются одновременно, каждая в своей вкладке;
  - сортировка по колонке и фильтр данных прямо на кассе;
  - просмотр структуры таблицы: колонки, индексы, ограничения;
  - SQL-консоль с историей запросов и закладками;
  - импорт и экспорт данных в CSV/JSON;
  - исправление ячеек с сохранением по первичному ключу.

- **Новые горячие клавиши** для быстрой работы: `Ctrl+V` — встроенный VNC,
  `Ctrl+Shift+V` — внешний VNC, `Ctrl+S` — SSH, `Ctrl+W` — WinSCP,
  `Ctrl+D` — редактор БД, `Ctrl+R` — рестарт ПО, `Ctrl+Shift+R` — перезагрузка кассы.

- **Программа запускается заметно быстрее**: окно появляется почти сразу,
  всё остальное подгружается в фоне. Вкладки касс подключаются параллельно,
  зависшая касса не мешает остальным.

- **История действий и уведомления** в нижней панели теперь работают как задумано:
  панель сама разворачивается при новом событии.

- Настройки сохраняются без ошибки, даже если в полях дробные значения.
- Меню «Команды» снова показывает все команды.
- Тест подключения в мастере первого запуска теперь проверяет и базу данных.

- Справка дополнена и приведена в соответствие с программой.

## v3.1.0 — 2026-07-02

### Что нового

- **Часть обновлений теперь приходит без перезапуска.** Панель инструментов,
  VNC-просмотр, редактор БД, все диалоги и виджеты теперь можно обновлять
  на ходу — достаточно переоткрыть диалог или переключить вкладку.
  Перезапуск требуется только при изменении ядра программы (подключение к БД,
  SSH, основной интерфейс).

- **Протокол обновлений исправлен.** Проверка и применение обновлений через
  сервер больше не даёт ложных «ничего нет», когда обновление есть.

- **Сборка манифеста автоматизирована.** `update_manifest.bat` и
  `make_master.bat` теперь работают — исправлена генерация `manifest.json`.

### Косметика

- Сообщения о статусе обновлений теперь корректные: «применено» только когда
  файлы реально скопированы, а не просто найдены.

## v3.0.0 — 2026-06-14

### Что нового

- **Смена темы работает мгновенно.** Переключили светлую/тёмную тему —
  применяется сразу везде, без перезапуска программы.

- **Внизу окна теперь полноценная панель.** Кликни — раскроется история
  действий по текущей кассе (что делали, когда, с каким результатом) и
  отдельная вкладка с уведомлениями программы. Историю можно настроить:
  хранить только пока открыта вкладка, или сохранять навсегда.

- **Все настройки в одном месте.** Раньше настройки были раскиданы по разным
  кнопкам — теперь один диалог с вкладками: Подключение, Программы, Общие,
  Обновления, Логи. Там же можно проверить подключение к кассе одной кнопкой.

- **Информация о кассе грузится быстрее.** Раньше ждали пока соберётся вся
  информация целиком. Теперь каждый блок (ОС, оборудование, ПО и т.д.)
  появляется сразу по готовности — не нужно ждать самый медленный блок.

- **Можно переименовывать оборудование.** Если в информации о кассе сканер,
  весы или другое устройство показывается непонятным кодом (или название
  неправильное) — кликни на него и задай своё название. Применится сразу и
  везде, на всех кассах.

- **Встроенный VNC — режимы качества картинки.** Под окном VNC появились три
  кнопки: 8 бит, 16 бит, 32 бит. Переключаются на ходу, без переподключения
  вручную — удобно если связь медленная и картинка тормозит.

- **Мастер первого запуска переделан.** Шаги понятнее: приветствие →
  подключение → проверка связи с тестовой кассой → пути к программам
  (KiTTY, VNC, WinSCP — можно найти автоматически) → готово.

### Что исправлено

- **Команды обновляются без перезапуска.** Если добавили/изменили команду
  на сервере — она подхватывается на лету, программу перезапускать не нужно.

- **Уведомления больше не дублируют значки** (было «✅✅ ...» — теперь один
  значок).

- **Подсказки (всплывающие текстовые окошки) стали читаемыми** в тёмной
  теме — раньше текст был тёмным на тёмном фоне.

- **Логи стали понятнее.** При ошибке подключения или выполнения команды в
  логах теперь видно подробности — что именно пошло не так и где.

- **Мастер первого запуска больше не зависает** и не вылетает на старте.

### Косметика

- Заглушка «Нажмите + чтобы добавить кассу» теперь по центру экрана, как и
  задумывалось.

- **Mover — доставка файлов и команд на кассы** — полная система автоматизации
  настройки касс после переустановки ПО:
  - Загрузка файлов конфигурации на кассу по типу (pos, touch, sco3)

  - Автоматическая настройка Loymax из CSV-файла
  - Автоматическая подстановка QRID из CSV-файла (POS)
  - Настройка COM-порта банковского терминала (POS)

  - Диалог прогресса выполнения с подробным логом

- **Конструктор сценариев Mover** — визуальный редактор для создания
  и редактирования сценариев:
  - Палитра блоков с drag-and-drop
  - Перетаскивание шагов для изменения порядка
  - Редактирование параметров каждого шага (файлы, команды, CSV, пути)
  - Сохранение сценариев в формате JSON

- **Дефолтный сценарий** — предустановленный сценарий полной настройки кассы,
  перенесённый из Telegram-бота

### Изменения интерфейса

- **Кнопки «Переустановка» и «Mover»** перенесены в правую часть тулбара

## v2.0.7 — 2026-03-17

### Новые возможности

- **Редактирование IP во вкладке** — сменить кассу без закрытия вкладки:
  - Двойной клик по заголовку вкладки
  - ПКМ → «Изменить IP»
  - Клавиша `F2` в активной вкладке
  - После подтверждения: отключение от старой кассы, подключение к новой

  Подсказка на главном экране дополнена горячей клавишей.

- **Python-скрипты как команды** — новый тип команды в редакторе:
  - Выбор типа при создании: SSH-команды / Python-скрипт
  - Python-скрипт сохраняется как `.py` файл в папке `commands/`
  - Фиксированная сигнатура: `async def execute(session, **kwargs)`
  - Доступ внутри скрипта: объект `session` (SSH, БД)
  - Отображается в меню «Команды» наравне с JSON командами

- **Патч-ноуты в разделе «О программе»** — новый раздел «Обновления» в справочнике,
  отображает содержимое файла `docs/patch.md`

- **Данные не восстанавливались при переподключении** — при реконнекте к кассе
  (без закрытия вкладки) теперь корректно сбрасывается кэш и данные загружаются заново

- **VNC: кнопки оставались неактивными** после открытия VNC в отдельном окне через
  панель инструментов — исправлено, кнопки не блокируются при запуске внешнего вьюера

- **Обновления не применялись** — исправлена проверка SHA файлов при сравнении
  с мастер-образом (SHA теперь всегда считается с реального файла на диске)

### Технические изменения

- `tab_manager.py`: добавлен `tabBarDoubleClicked`, `QShortcut(Ctrl+T)`, пункт
  «Изменить IP» в контекстное меню вкладки
- `cash_session_widget.py`: метод `start_ip_edit()`, сброс `_info_loaded` при
  реконнекте, `open_vnc_external()` не эмитит `connecting`
- `command_loader.py`: поддержка `.py` файлов команд
- `command_editor.py`: выбор типа команды (SSH / Python), редактор кода
- `help_dialog.py`: разделы «Вкладки касс», «Редактор команд», «О программе»
  дополнены; новый раздел «Обновления»
- `main_window.py`: `QShortcut(Ctrl+T)`
