# Скриншоты для справочника CashControl

Положите PNG-файлы в эту папку — они автоматически появятся в справочнике.

| Файл                          | Раздел справочника                    |
|-------------------------------|---------------------------------------|
| overview_main.png             | Обзор → главное окно                  |
| tabs_overview.png             | Вкладки → панель вкладок              |
| add_cash_dialog.png           | Вкладки → диалог добавления           |
| toolbar.png                   | Панель инструментов                   |
| commands_menu.png             | Панель инструментов → команды         |
| settings_connection.png       | Настройки → Подключение               |
| settings_programs.png         | Настройки → Программы                 |
| settings_general.png          | Настройки → Общие                     |
| db_viewer_main.png            | DB Viewer → главное окно              |
| db_table_view.png             | DB Viewer → просмотр таблицы         |
| db_sql_console.png            | DB Viewer → SQL консоль              |
| command_editor.png            | Редактор команд                       |
| logs_viewer.png               | Журнал действий                       |
| first_start_connection.png    | Первый запуск → настройки             |
| first_start_add_cash.png      | Первый запуск → добавление кассы      |
