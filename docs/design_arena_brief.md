## 1. АНТИПРИМЕР — так делать ЗАПРЕЩЕНО

Десять нейросетей подряд выдали одно и то же. Вот этот стереотип, целиком:

- «Операторский Fluent / Fluent 2 Compact / Density» — серо-синий или
  серо-графитовый фон (#F3F3F3 / #202020-подобные), **один синий или
  teal-акцент** (#0078d4, #0067C0, #2A9B8F, #2864DC — всегда что-то такое);
- «слоистость вместо теней»: карточки `bg_surface` + бордер 1px + радиус
  6–10px; hairline-разделители; «глаз цепляется за статус, а не за декор»;
- тулбар: ряд кнопок «иконка над подписью» 60–88px шириной;
- моноширинный шрифт для IP/версий «как в терминале»;
- Segoe UI + Cascadia/Consolas; WCAG AA; «переключение тем на лету»;
- формулировки: «операторский пульт», «приборная панель», «дисциплина

**Если твой ответ можно описать этими словами — он бракуется без чтения.**

Это не значит «нельзя красиво» или «нельзя читаемо». Это значит: ищи
образ НЕ из этого семейства. Направления-спarks (не обязательны, просто
показывают масштаб допустимой смелости): ретро-терминал amber/green
phosphor; швейцарская типографика / editorial-сетка с крупным кеглем;
брутализм с жёсткими чёрными линиями; SCADA/индустриальные панели 90-х;
тёмная «ночная смена» с одним тёплым цветом; бумажная картотека/архив;
игровой HUD. Можешь придумать своё — главное, чтобы это было НЕ Fluent.

## 2. Приложение и сценарий

**CashControl** — Windows-инструмент оператора для удалённого управления
парком кассовых терминалов (POS/SCO) по SSH и PostgreSQL. Один оператор
держит 3–15 касс открытыми весь рабочий день. Python 3.12 + PySide6 +
qfluentwidgets, интерфейс русский, монитор 1366×768.

Сценарий: вкладки восстановлены → кассы подключаются волнами → по точке
на вкладке видно связь → клик по вкладке: слева VNC-экран кассы, справа
карточки данных → действия с тулбара → при проблемах карточка «Проблемы»
подсказывает причину. Плюс DB Viewer (SQL) в отдельном окне.

## 3. Главное окно (состав зон — фиксирован, порядок зон не менять)

```
┌──┬──────────────────────────────────────────────┐
│С │ [вкладка 172.18.105.97 •][+]                 │
│И ├──────────────────────────────────────────────┤
│Д │ [Перезапуск][Reboot][VNC][SSH][WinSCP][DB]…  │
│Б ├──────────────────────────────────────────────┤
│А │ ┌──────────────┐ ┌─────────────────────────┐ │
│Р │ │  VNC-экран   │ │ Карточки: Касса /       │ │
│  │ │              │ │ Оборудование / Прочие / │ │
│  │ │              │ │ Проблемы                │ │
│  │ └──────────────┘ └─────────────────────────┘ │
├──┴──────────────────────────────────────────────┤
```

### 3.1 Сайдбар
Вертикальная колонка: круглые кнопки **Настройки**, **Помощь**; внизу
мелкая версия. Иконки — только `FluentIcon`.

### 3.2 Вкладки касс
Вкладка = IP (`172.18.105.97`) + точка пинга + крестик; кнопка `[+]`.
Точка: ok/slow/timeout/неизвестно (семантика цветов зелёный/жёлтый/
красный/серый — неизменна, оттенки твои). Контекстное меню: Закрыть /
Изменить IP / Обновить / Копировать IP. Вкладок бывает 15+.

### 3.3 Тулбар действий
Кнопки с русской подписью: Перезапуск, Reboot (опасное — подтверждение),
VNC, SSH, WinSCP, DB, Обновить, Команды (меню). Для POS — блок
виртуальной клавиатуры. Меню «Команды»: команды из TOML + пункт ручного
выбора типа кассы.

### 3.4 Рабочая область (сплиттер)
Слева VNC-панель (пусто / подключение / live-экран; кнопки Подключить/
Отключить/Во весь экран/глубина цвета). Справа — скролл карточек:

| Карточка | Поля label → value |
|---|---|
| Касса | Тип (pos/touch/sco/sco3), версия ПО, CPU, ОС |
| Оборудование | ФР (COM2, «Штрих-Т»), дисплей клиента, сканер (VID/PID), весы, клавиатура, банк-терминал |
| Прочие | DNS, Loymax, QRID |
| Проблемы | severity (warning/error) + текст |

Состояния карточки: загрузка → данные / таймаут / ошибка. До подключения
вся область — состояние «Подключение…» (+ ошибка и «Повторить»).

### 3.5 Статус-бар
Свёрнут — строка статуса; раскрывается вверх: два списка (История
действий с временем и успех/ошибка; Уведомления) + очистка.

## 4. Диалоги

- **Настройки**: левое меню страниц (Подключение: логины/порты/пароли-
  multiline; Общие: тема/история; Программы: пути+шаблоны аргументов;
  Логи), внизу Сохранить/Отмена.
- **Мастер первого запуска**: 5 шагов (Приветствие → Подключение → Тест →
  Программы → Финиш).
- **Редактор команд**: форма + live-предпросмотр; **Результат команды**:
  stdout/stderr моно; **Логи**: файл+поиск+текст; **Помощь**: дерево тем +
  HTML-страница; **Добавить кассу / Алиасы**: малые формы.

## 5. DB Viewer (отдельное окно)

Слева: комбобокс базы, поиск, список таблиц (тип + имя + счётчик строк).
Центр: грид — серверная пагинация, фильтр, сортировка, редактирование по
PK, импорт/экспорт CSV/JSON; колонок бывает 20+. Низ: выдвижная SQL-
консоль (подсветка, история, автокомплит, Ctrl+Enter) + строка результата
(«12 400 строк · 380 мс» / ошибка).

## 7. Рамки кода (жёстко)

### 7.1 Стек
PySide6 6.8 + qfluentwidgets 1.11 (их виджеты можно свободно использовать).
Никаких новых библиотек, web-технологий, поставных шрифтов (разрешены
только предустановленные в Windows: Segoe UI, Cascadia Mono, Consolas,
Arial; НЕ Inter/JetBrains — их нет на чистой машине).

### 7.2 QSS в Qt — что можно и что нельзя
- Есть: цвета/фоны/борды/радиусы/padding, `:hover/:pressed/:checked/
  :disabled/:focus`, селекторы по **objectName** (`#Name`) и по
  **dynamic property** (`[state="x"]`).
- **НЕТ селекторов классов** (`.infoCard` — не работает, это CSS, не QSS).
- НЕТ: box-shadow, blur, transition, letter-spacing.
- Тени — только QGraphicsDropShadowEffect точечно (дорого на больших
  поверхностях — обосновывай).
- Глобальный селектор `QWidget { background: … }` запрещает
  qfluentwidgets рисовать свои виджеты — не используй его для фонов.

### 7.4 Логика неприкосновенна
Не менять классы, методы, сигналы/слоты, потоки, async, форматы данных,
порядок инициализации. Разрешено: QSS, dynamic properties, замена виджета
на виджет той же библиотеки, декоративные виджеты-обёртки, точечные
QGraphicsEffect (с обоснованием).

### 7.5 Доступность и контент
WCAG AA в обеих темах; русский текст длиннее английского; минимум
1366×768; severity — никогда только цветом (иконка/текст/форма).
