Пользовательские типы касс (overlay).

Файлы отсюда перекрывают встроенные определения из
runtime/app/cashcontrol/core/cash_types/bundled/ по имени файла.

Чтобы добавить свой тип: скопируйте любой .toml из bundled сюда,
поменяйте id/name/features — тип появится в выборе и в автоопределении.
Правила автоопределения — в каталоге detection/.
